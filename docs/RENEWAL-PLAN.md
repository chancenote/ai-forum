## 0. 한 줄 요약

지금 사이트는 "우리가 무엇을 하는 모임인지" 설명하는 **소개 페이지**다.
리뉴얼 후에는 "이번 달 7시에 무슨 일이 벌어지는지, 내가 무엇을 들고 나오는지"를 보여주고
**신청까지 끌고 가는 전환 페이지**가 되어야 한다.

핵심 전환 지표(KPI)는 단 하나로 잡는다. **방문 → 멤버 신청 전환율.**

## 1. 레퍼런스 분석 — if(kakao)에서 가져올 것 / 버릴 것

### 1-1. 가져올 것 (7가지 디자인 문법)

| # | 디자인 장치 | if(kakao)의 방식 | Morning AI Forum 적용안 |
|---|---|---|---|
| 1 | 코드 신택스 모티프 | `if(kakao)` 자체가 로고이자 컨셉 | `morning(AI)` / `while(learning)` 모노스페이스 라벨 시스템 |
| 2 | 다크 캔버스 + 단일 고채도 액센트 | 검정 배경 + 카카오 옐로 | 나이트 인디고 배경 + **선라이즈 앰버** (아침 = 일출 그라디언트) |
| 3 | 초대형 디스플레이 타이포 | 화면을 꽉 채우는 슬로건 | `가장 생산적인 아침` 8vw 급 헤드라인 |
| 4 | 카운트다운 + 등록 밴드 | 신청 마감 D-day 상시 노출 | **다음 세션 D-day 카운터**(매월 둘째 주 금요일 자동 계산) |
| 5 | 필터형 세션 그리드 | 트랙/일자별 50여 개 세션 필터 | **7개 세션 태그 필터**(#CASE #WORKFLOW #AGENT …) |
| 6 | 마퀴 티커 | 키워드 흐름 띠 | `AI for Problem Solver` 무한 스크롤 띠 |
| 7 | 스크롤 리빌 모션 | 섹션별 등장 애니메이션 | IntersectionObserver 기반 스태거 리빌 |

### 1-2. 버릴 것

- **규모 과시형 구성.** if(kakao)는 50여 세션·수천 명 규모다. 우리는 **20석 한정 · 70분**이다.
  숫자로 이기려 하면 진다. **밀도(70분에 결과물 1개)로 이긴다.**
- **연 1회 이벤트 IA.** 우리는 연 1회가 아니라 **12개월 반복 습관**이다.
  "행사 안내"가 아니라 **"시즌제 커뮤니티"** 구조로 간다.
- **추첨 등록.** 우리는 추첨이 아니라 **심사 + 기여 약속(연 2회 발표)** 기반이다.

## 3. 새 디자인 시스템

### 3-1. 컨셉 — "AI의 아침(Dawn of AI)"

운영기획서의 문장을 그대로 디자인 언어로 번역한다.

> "AI의 아침은 조용히 시작되지만, 그 격차는 시간이 갈수록 벌어질 것입니다."

- 배경: 새벽 직전의 **나이트 인디고**
- 액센트: 지평선에서 올라오는 **선라이즈 앰버**
- 히어로 하단에 **호라이즌 글로우**(일출 그라디언트)를 깔아 "아침"을 은유

### 3-2. 컬러 토큰

```
--ink-900 : #07070B   캔버스
--ink-800 : #0D0D14   섹션 대체 배경
--ink-700 : #14141E   서피스(카드)
--ink-600 : #1D1D2A   서피스 호버
--line    : rgba(255,255,255,.09)

--fg      : #F5F5F7   본문
--fg-dim  : #9A9AAB   보조

--amber   : #FFB01F   프라이머리 (기존 골든 옐로 계승·정제)
--amber-2 : #FFD782
--violet  : #7C5CFF   보조 액센트(태그·차트)

--dawn : linear-gradient(90deg,#1B1038,#6E2E5B,#E8622C,#FFB01F,#FFE9A8)
```

기존 골든 옐로 테마를 **버리지 않고 정제**한다. (직전 커밋에서 확정한 브랜드 자산)

### 3-3. 타이포그래피

- 국문: **Pretendard** (폴백 Noto Sans KR) — 한글 가독성 최우선
- 영문 디스플레이: **Outfit** 800/900
- 라벨·수치: **JetBrains Mono** — 코드 신택스 모티프 담당
- 스케일: `clamp()` 기반 유동형. 히어로 H1 `clamp(2.6rem, 7.2vw, 6.4rem)`

### 3-4. 모션

- 스크롤 리빌(스태거 60ms), 스크롤 프로그레스 바, 숫자 카운트업
- 마퀴 티커, 나브 액티브 섹션 추적
- `prefers-reduced-motion` 전면 대응

## 5. 포럼 멤버 확보 방안

### 5-1. 문제 정의

현재 이메일 입력 1줄로는 **"아무나 오세요"** 신호를 준다.
아침 7시에 나올 사람은 아무나가 아니다. **문턱을 낮추지 말고, 문턱을 명확하게** 만든다.
희소성(20석) + 기여 약속(연 2회 발표)이 오히려 신청률을 올린다.

### 5-2. 3단계 합류 퍼널

```
 [1] 신청서 제출          [2] 오리엔테이션 콜        [3] 게스트 참관         [4] 정식 합류
 ─────────────────  →   ─────────────────  →  ────────────────  →  ────────────────
 관심 세션 / 발표 가능      15분 통화                1회 무료 참관            시즌 멤버 등록
 주제 / 추천인 기입        기여 가능 영역 확인         분위기·수준 직접 확인      연 2회 발표 약속
```

"먼저 한 번 보고 결정하세요"(게스트 참관)가 심리적 저항을 가장 크게 낮춘다.

### 5-3. 멤버 등급 3종

| 등급 | 정원 | 조건 | 혜택 |
|---|---|---|---|
| **Core Builder** | 6명 | 연 4회 이상 발제 · 세션 리드 | 아카이브 전체 · 운영 의사결정 참여 |
| **Member** | 14명 | 연 2회 이상 사례 발표 | 아카이브 전체 · 프라이빗 채널 |
| **Guest** | 회당 2석 | 멤버 추천 필수 | 1회 참관 · 당회 자료 |

### 5-4. 확보 채널 5선 (실행 우선순위)

1. **코어 멤버 다이렉트 추천** — 전북연구원 / 전북도청 / 전북산학융합원 / 넥스트코웍 네트워크.
   1인당 3명 추천 = 초기 12명 확보. **가장 빠르고 확실한 채널.**
2. **게스트 시딩** — 매회 게스트 2석을 고정 운영. 참관 → 전환율 목표 50%.
3. **콘텐츠 역유입** — 매월 세션 결과물 1건을 공개 아카이브로 발행(프롬프트 카드 등).
   링크드인/브런치 배포 → 사이트 유입 → 신청.
4. **지역 앵커링** — "가장 AI를 잘 활용하는 도시(전북)" 내러티브.
   기관·대학·산업계 대상 공동 세션 제안.
5. **넥스트코웍 교육/컨설팅 고객 전환** — 기존 AI 교육 수료생 대상 멤버 초대.

### 5-5. 이탈 방지

- 세션 종료 24시간 내 **아카이브 링크 발송**(참석 못 해도 자산은 남는다)
- 분기 1회 **오프라인 확장 세션**
- 발표 부담 완화: **5분 트렌드 브리핑**도 정식 발표로 인정

## 6. 주요 콘텐츠 임팩트 강화

PT 자료의 알맹이가 사이트에 전혀 안 올라와 있다. 세션 카드를 **4블록 구조**로 전면 재작성한다.

```
┌─ 01  AI 활용사례 PT/시연 발표 ────────────── #CASE #EXPLORE #ARCHIVE ─┐
│  "배우면서 가르쳐라 — 발표와 공유로 지식 정착률 90%"                      │
│                                                                    │
│  ▸ 세션 특징        현업에서 검증된 '진짜 써먹힌' 사례 / 라이브 시연 /        │
│                    문제정의→도구→프롬프트→워크플로우 전 과정 공개            │
│  ▸ 이런 분께        내 업무에 적용 가능한 레퍼런스가 필요한 분                │
│  ▸ 핵심 결과물      PT/PDF 또는 노션 정리본 (핵심 흐름 + 링크 + 템플릿)      │
│  ▸ 기대 효과        재현 가능한 시나리오 & 적용 포인트 도출                 │
└────────────────────────────────────────────────────────────────────┘
```

### 임팩트를 만드는 3가지 장치

1. **숫자로 말한다** — "지식 정착률 90%", "24시간 내 적용 시 기억률 75%",
   "하루 30분 절감 = 연 180시간", "12개월 = 상위 10%".
   추상적 가치 서술 대신 PT에 이미 있는 수치를 전면 배치.

2. **결과물을 먼저 보여준다** — 모든 세션 카드에 `핵심 결과물`을 고정 노출.
   "무엇을 배우나"가 아니라 **"무엇을 들고 나가나"**로 프레임을 바꾼다.

3. **태그 필터로 탐색시킨다** — 방문자가 자기 관심사(#AGENT, #AUTOMATION)로
   즉시 좁힐 수 있게 한다. 7개를 다 읽게 하지 않는다.
