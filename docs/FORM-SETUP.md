# 신청서 연결 가이드

사이트의 멤버 신청서를 **실제로 받는 곳**에 연결하는 방법입니다.
코드는 건드리지 않습니다. **`config.js` 파일 하나만** 수정하면 됩니다.

---

## 0. 지금 상태

기본값은 `mailto` 입니다. 신청 버튼을 누르면 신청자의 **메일 앱이 열리고**,
내용이 자동으로 채워진 메일을 `contact@nextcw.com` 으로 보내게 됩니다.

- 장점: 아무 설정 없이 지금 바로 동작합니다
- 단점: 신청자가 메일을 직접 보내야 하므로 **중간 이탈이 생깁니다**.
  모바일에서 메일 앱이 없으면 아예 동작하지 않습니다

**그래서 아래 방법 중 하나로 바꾸는 것을 권장합니다.** 10분이면 끝납니다.

---

## 1. 구글폼 (추천 · 무료 · 제한 없음)

신청 데이터가 **구글 시트에 자동으로 쌓입니다.** 가장 실용적입니다.

### 1-1. 구글폼 만들기

[forms.google.com](https://forms.google.com) 에서 새 폼을 만들고 **단답형 7개**를 아래 순서로 추가합니다.

| 순서 | 질문 | 유형 |
|---|---|---|
| 1 | 이름 | 단답형 |
| 2 | 소속/직함 | 단답형 |
| 3 | 이메일 | 단답형 |
| 4 | 신청 유형 | 단답형 |
| 5 | 관심 세션 | 단답형 |
| 6 | 발표 가능 주제 | 장문형 |
| 7 | 추천인 | 단답형 |

> 사이트가 값을 만들어 보내므로, 구글폼 쪽은 **전부 단답형/장문형**으로 두세요.
> 객관식으로 만들면 값이 안 맞아 저장되지 않습니다.
> **'필수' 체크는 모두 해제**하세요. (빈 값이 올 수 있습니다)

### 1-2. 전송 주소와 entry ID 찾기

1. 폼 편집 화면에서 우측 상단 **보내기 → 링크(🔗)** 로 폼 주소를 복사합니다.
   주소가 `https://docs.google.com/forms/d/e/**1FAIpQL...**/viewform` 형태입니다.
2. 맨 뒤 `viewform` 을 **`formResponse`** 로 바꾼 것이 전송 주소입니다.
3. 폼 미리보기 화면에서 **마우스 우클릭 → 페이지 소스 보기**(Ctrl+U) 후,
   `Ctrl+F` 로 **`entry.`** 를 검색합니다.
   `entry.1234567890` 같은 값이 질문 순서대로 나옵니다. 7개를 순서대로 적어두세요.

### 1-3. config.js 수정

```js
form: {
    provider: 'googleForm',
    endpoint: 'https://docs.google.com/forms/d/e/1FAIpQL.../formResponse',
    googleFormFields: {
        name:     'entry.1111111111',   // 1. 이름
        org:      'entry.2222222222',   // 2. 소속/직함
        email:    'entry.3333333333',   // 3. 이메일
        tier:     'entry.4444444444',   // 4. 신청 유형
        interest: 'entry.5555555555',   // 5. 관심 세션
        topic:    'entry.6666666666',   // 6. 발표 가능 주제
        referrer: 'entry.7777777777'    // 7. 추천인
    }
}
```

### 1-4. 응답 확인

구글폼 **응답 탭 → 시트로 연결**을 눌러두면 신청이 실시간으로 시트에 쌓입니다.
시트에서 **도구 → 알림 규칙**을 켜면 신청이 들어올 때 메일로 알림도 받습니다.

## 2. Formspree (가장 간단 · 월 50건 무료)

1. [formspree.io](https://formspree.io) 가입 후 New Form 생성
2. 발급된 주소(`https://formspree.io/f/abcdwxyz`)를 복사
3. `config.js` 수정:

```js
form: {
    provider: 'formspree',
    endpoint: 'https://formspree.io/f/abcdwxyz'
}
```

신청이 들어오면 **등록한 메일로 바로 전달**됩니다. 대시보드에서도 확인됩니다.

---

## 3. 자체 엔드포인트 (Make / n8n / Apps Script)

JSON 을 받는 주소가 있다면:

```js
form: {
    provider: 'webhook',
    endpoint: 'https://hook.us1.make.com/xxxxxxxx'
}
```

아래 형태의 JSON 이 `POST` 됩니다.

```json
{
  "name": "이종찬",
  "org": "넥스트코웍 / 대표",
  "email": "ceo@nextcw.com",
  "tier": "Member",
  "interest": "Agent 제작, 업무자동화",
  "topic": "보고서 초안 작성 자동화",
  "referrer": "(없음)"
}
```

> **CORS 주의**: 엔드포인트가 `Access-Control-Allow-Origin` 헤더를 내려주지 않으면
> 브라우저가 요청을 막습니다. Make·n8n 은 기본 허용이지만,
> Apps Script 는 배포 시 **"액세스 권한: 모든 사용자"** 로 설정해야 합니다.

## 4. 연결 후 반드시 확인할 것

바꾼 뒤 **직접 한 번 신청해 보세요.** 확인 항목은 3가지입니다.

1. **성공 화면이 뜨는가** — 뜨면 전송이 실제로 성공한 것입니다.
   이 사이트는 전송이 실패하면 성공 화면을 보여주지 않습니다.
2. **수신처에 데이터가 도착했는가** — 구글 시트 / Formspree 대시보드 확인
3. **실패 시 안내가 뜨는가** — 주소를 일부러 틀리게 바꿔 테스트해 보세요.
   실패하면 빨간 안내와 함께 **'메일로 보내기'** 버튼이 나타나야 합니다

## 5. 함께 관리하는 값들

`config.js` 에는 신청서 외에도 운영 중 자주 바뀌는 값이 모여 있습니다.

| 항목 | 설명 |
|---|---|
| `seats` | 정원과 **잔여 석**. 줄이면 사이트에 `· 잔여 5` 로 바로 표시됩니다 |
| `nextSessionOverride` | 공휴일 등으로 **날짜를 옮길 때만** 지정. 평소엔 비워두면 둘째 주 금요일 자동 계산 |
| `members` | 코어 멤버 **사진 파일명** (`assets/members/` 폴더에 넣기) |
| `archive` | **공개 아카이브** 목록. 비어 있으면 해당 영역이 아예 보이지 않습니다 |
| `analytics` | 이벤트 측정 on/off |

## 6. 전환율 측정

사이트에 Google Analytics / Vercel Analytics / Plausible 중 **아무거나 설치하면**
아래 이벤트가 자동으로 잡힙니다. 별도 코드 작업은 없습니다.

| 이벤트 | 의미 |
|---|---|
| `cta_click` | 신청 버튼 클릭 (어느 섹션에서 눌렀는지 포함) |
| `sim_tab` | 라이브 다이어그램에서 다른 업무를 골라봄 |
| `session_filter` | 세션 태그 필터 사용 |
| `session_open` | 세션 상세 펼침 |
| `archive_open` | 공개 아카이브 항목 클릭 |
| `apply_start` | 신청서에 처음 입력하기 시작 |
| `apply_submit` | 신청 버튼 누름 |
| `apply_success` | 전송 성공 |
| `apply_error` | 전송 실패 (원인 메시지 포함) |

**핵심 지표인 신청 전환율**은 `cta_click → apply_start → apply_success`
세 단계의 비율로 바로 확인할 수 있습니다.
어디서 이탈하는지 보이면 그 지점만 고치면 됩니다.
